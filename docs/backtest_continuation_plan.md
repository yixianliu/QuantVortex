## 二、每条建议的具体实施步骤（预期输出 + 完成标准）

### R1 · 绩效图表视觉/交互深化（`ui/perf_chart.py`）
- **1.1 悬停提示**：捕获 `mouseMoveEvent`，x→索引映射（新增纯函数 `index_at(x)`，便于单测）；`QToolTip` 展示日期/资金/收益率/回撤%。
  - 输出：`BacktestPerfChart` 悬停可读点信息。完成标准：`index_at` 单测正确；offscreen 注入数据后 tooltip 文本含关键字段。
- **1.2 数值轴标签**：左侧画资金刻度值，右侧画回撤%刻度。
  - 完成标准：标签存在且不重叠。
- **1.3 时间轴标签**：用 `self._dates` 在底部等距画 ≥2 个日期刻度。
  - 完成标准：≥2 个日期标签渲染。
- **1.4 基准叠加**：新增 `set_benchmark(series)` 画虚线"买入持有"参考线（归一化）。
  - 完成标准：提供时绘制、不提供时不崩；测试断言标志。
- **1.5 内联指标注解**：右上角小字块展示夏普/年化/最大回撤（来自 metrics dict）。
  - 完成标准：注解随 `set_metrics` 渲染。
- **1.6 导出 PNG**：`export_png(path)` 用 `grab().save()`。
  - 完成标准：生成非空 PNG。
- **R1 完成标准**：6 步全落地；`py_compile` 通过；新增 `tests/e2e/test_perf_chart_ux.py` 全过；生成预览图。

### R2 · 手动/交割交易路径接入主流程（`ui/backtest_page.py` + `core/engine.py`）
- **2.1 模式开关**：在 `BacktestCenterPage` 控制条加"手动回测"勾选（与自动模式互斥，复用现有 3 模式互连模式）。

- **2.3 接入渲染**：手动运行 → Worker → snapshot/metrics → 复用 `_update_curves` / `_fill_perf_chips` 驱动图表与 KPI。
- **2.4 交付日强平 E2E**：合成一个临近交割日的合约，验证 UI 流程中触发 `flatten_all` 且曲线/日志正确。

- **R2 完成标准**：offscreen 驱动"自动关→手动开→运行→图表填充→历史行新增→交付日强平可见"全链路通过。

### R3 · 联动深化（`backtest_page.py` ↔ `predict_ops_page.py`）
- **3.1 回测→预测**：点击盈利策略行或"🔗应用并分析"按钮 → `window._goto_page("predict")` + `pg.set_symbol(sym,"D")` + 预载该策略基因（扩展 `set_symbol` 接受可选 gene）。

- **R3 完成标准**：往返测试（回测行→预测信号展示→回测手动同 gene 运行）通过。

## 五、关键决策节点（至少两方案对比）

### 决策节点 A — 优先级/范围：先打磨 UX+手动，还是先接真实数据？
- **方案 A（推荐）**：先完成 R1→R2→R3（仍基于合成数据）。
  - 优点：最快形成可用、可演示的期货回测；先把引擎逻辑去风险；无外部依赖；测试保持封闭可复现。
  - 缺点：结果仍跑在合成数据上，尚未"真实行情"。
- **方案 B**：提前铺 R4 真实数据接入。
  - 优点：立刻真实；直接用真实行情校验引擎。
  - 缺点：被外部 API/额度阻塞；数据质量易陷坑；延迟 UX/手动收益；难做封闭测试。

### 决策节点 B — 手动回测如何暴露？
- **方案 B1（推荐）**：在 `BacktestCenterPage` 内加"手动回测"模式开关（与自动互斥）。
  - 优点：单页、状态/UI 一致，复用全部图表/KPI/store 代码。
  - 缺点：页面逻辑增长；模式切换略复杂。
- **方案 B2**：单独开"手动回测"页/标签。
  - 优点：职责分离，无模式切换复杂度。
  - 缺点：图表/KPI/store 代码重复；双份真相源；维护面更大。

### 决策节点 C（若选 R4）— 真实数据源 · 裁决（2026-07-28）
- **方案 C1**：Neodata（项目已有 `neodata-financial-search` 能力）→ **未采用**：connector 当前 disconnected，且涉额度/计费。
- **方案 C2**：akshare（免费、品种全）→ **采用为主源**：1.18.64 已装、零认证、沙箱实测可联网拉真实期货日线（rb0 主力 4208 根）。
- **方案 C3**：本地 CSV/Parquet 落库后回放（最可控）→ **采用为离线兜底**：`data/real_samples/rb_SHFE_D.csv` + `CsvFeed`。
- **最终裁决**：C2 + C3 组合，优于原计划 C1。真实源用 akshare，离线回放用 CsvFeed，二者同 `DataFeed` 契约，`MarketDataManager` 工厂已支持 `source="akshare"/"csv"`。
