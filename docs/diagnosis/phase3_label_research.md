# 第三轮 B · 标签体系改造实验（严格样本外）

> 目标不是把命中率调高，而是换一个**更可能成立且能被验证**的预测目标。
> 本轮只做研究与评估：不改 `ui/`、不动数据库、不覆盖任何模型权重、不 commit、不联网下载。

---

## 0. 一句话结论

**换标签后没有出现可交易边际。**
唯一统计显著的候选是「未来 5 日已实现波动率三分位」：准确率 51.73% vs 无技能基准 39.25%
（日期聚类 95% CI [50.92%, 52.55%]，13/21 品种显著），但它**不含方向信息**，按验证段选出的
门控接到方向信号后，扣成本净夏普仍为 −0.186。方向分类、大涨/大跌三分类、|收益| 超阈值、
横截面相对强弱（rank IC）全部不显著；区间标签显著但方向是「覆盖过度」（区间过宽），
不是边际。因此整体结论是：**现有日线数据与特征集不足以产生可交易边际。**

## 1. 方法与口径

### 1.1 数据与样本

| 项目 | 内容 |
|---|---|
| 数据源 | `data/sina_cache/*0.csv`（本地主力连续日线，未联网下载） |
| 品种 | 21 个，覆盖黑色（rb/hc/i/j/jm）、有色（cu/al/zn）、贵金属（au/ag）、能化（ta/ma/ru/bu）、农产品（m/y/sr/cf）、金融（IF/IC/IH） |
| 数据版本指纹 | `7eccd17367d554bb`（所选 CSV 内容 sha256 前 16 位） |
| 样本量 | 训练 963~1219 / 验证 243 / **测试 1162~1164 每品种**，测试合计 **24,442** 条 |
| 时间切分 | train 2016-01-01 ~ 2020-12-31；validation 2021-01-01 ~ 2021-12-31；**test 2022-01-01 ~ 2026-11-03** |
| 随机种子 | `20261104`（sklearn 模型确定性，种子用于打乱标签对照） |

每个品种测试段 ≥800 的要求满足（实际 1162~1164）。

### 1.2 特征工程（重点是特征，不是换模型）

时序特征（14 个，全部为因果窗口，t 时点只用到 ≤ t 的 bar）：

`ret1, mom5, mom20, mom60, vol20, vol60, atr14, range_pos, oi_chg5, oi_chg20, vol_ratio, amp, vp_div, ret_skew20`

横截面特征（12 个，同日不同品种之间的相对位置）：
- 市场内排名：`xs_mom5, xs_mom20, xs_vol20, xs_oi_chg5, xs_vol_ratio, xs_range_pos`
- 板块内排名：`xs_mom20_cat, xs_oi_chg5_cat, xs_vol20_cat`
- 板块动量与相对强弱：`sector_mom5, sector_mom20, rel_mom20`

缺失值用 **train 段中位数**填充，标准化用 **train 段 RobustScaler(5%~95%)**；
验证/测试段只做 transform，不参与拟合。

**数据缺口（本轮无法构造）**：无分钟线（0/71 品种）、无近远月单合约（只有主力连续 `*0`）、
无分席位持仓、无跨品种价差同步数据。因此期限结构/基差/月差、席位拥挤度、日内量价特征
全部缺席；这也是后文「需要什么数据」的直接来源。

### 1.3 候选标签（逐个独立评估）

| 标签 | 定义 | 阈值来源 |
|---|---|---|
| L0 方向分类（对照） | `fwd1 > 0` | 无 |
| L1 波动率状态 | `fwd5` 未来 5 日已实现波动率三分位（低/中/高） | **train** 33%/67% 分位 |
| L2 大波动 | `|fwd5|` 是否超阈值 | **train** 70 分位 |
| L3 三分类 | 大跌 / 震荡 / 大涨 | **train** `fwd5` 30%/70% 分位 |
| L4 横截面相对强弱 | 同日 21 品种未来 5 日收益排名（rank IC 为主指标） | 无 |
| L5 预测区间 | Ridge 点预测 + **validation** 残差 10/90 分位 → 80% 名义区间 | 验证段残差 |

标签只由未来收益构造，绝不进入特征；L1/L2/L3 的阈值只用训练段估计。

### 1.4 模型与调参

- 回归类（L5、L4）：`SimpleImputer(median) → RobustScaler → Ridge`；
  回归 alpha 在 `{0.1, 1, 10}` 里由**验证段** MSE（L4 为验证段平均 rank IC）选择。
- 分类类（L0~L3）：`SimpleImputer(median) → RobustScaler → LogisticRegression`；
  C 在 `{0.1, 1, 10}` 里由**验证段准确率**选择。
- 未引入 torch/lightgbm；无 GPU 依赖，纯 sklearn 降级路径。
- **测试段没有参与任何超参、阈值或特征选择。**

### 1.5 统一评估口径

全部调用 `futures_quant.ai.evaluation`：
- `probability_hit_rate` / `wilson_interval`：命中率/准确率、基准率、Wilson 95% CI；
- `net_performance`：预测 → 仓位（±1/0）→ 真实下一根收益 − 换手成本；
- `estimate_cost_rate`：按合约乘数/最小变动价位/手续费逐品种计算，手续费按手 + 1 tick 滑点
  （全样本平均单边成本约 3.05 bps）。

为处理「同一天 21 个品种高度相关」，额外报告**按交易日聚类的 95% CI**
（逐日准确率/命中率 → 日均值 ± 1.96×SE），显著性仍与无技能基准比较。

### 1.6 防泄漏证据

1. **因果自检 PASS**：扰动第 301 行之后的 OHLCV/OI，前 301 行特征逐值不变
   （`history_features_unchanged=True`，`future_features_changed=True`）。
2. **打乱训练标签对照**：把训练标签随机打乱后重训。

| 对照 | 准确率 |
|---|---|
| L1 原模型 | **51.73%** |
| L1 训练多数类（无技能） | 39.25% |
| L1 打乱训练标签（3 次平均） | 32.91% |
| L0 打乱训练标签（3 次平均） | 49.79%（基准 50.27%，符合预期） |

打乱标签后 L1 回落到 1/3 随机水平，说明 51.73% 不是流程泄漏，而是波动率聚集的真实可预测性。

> 口径说明：L0 是「在同一特征集/同一时间切分上重建的方向分类」，不是生产模型本身。
> 这样做的目的是隔离**标签差异**；生产模型的样本外数字见
> `docs/diagnosis/phase2_model_eval.md`（rb 51.2% vs 基准 53.1%、i 51.5% vs 50.5%、
> cu 52.1% vs 54.2%、IF 47.9% vs 51.8%，全部不显著）。

## 3. 逐标签细节

### 3.1 L0 方向分类（对照）

- 51.7k 训练样本、24.4k 测试样本，命中率 50.04%，基准率 50.27%，CI 下界低于基准。
- 分年度命中率 51.57% / 49.88% / 49.00% / 49.70% / 50.04%（2022~2026），无一年显著。
- 逐品种 0/21 显著；毛夏普已为负（−0.146），扣成本后 −0.257。
- 与 phase2 生产模型结论一致：**方向标签没有可交易技能**。

- 它**不含方向信息**，无法单独产生多空收益；

### 3.3 L2 大波动（|未来 5 日收益| 超训练期 70 分位）

- 准确率 49.98% vs 基准 50.27%，0/21 显著；分年度全部不显著。
- 门控阈值 tau 由验证段选出，但分布分散（0.2~0.8 都有），无稳定最优阈值。
- 净夏普 pooled −0.182、中位数 −0.085，毛夏普已为负。

### 3.4 L3 大跌/震荡/大涨（训练期 30/70 分位）

- 准确率 42.26% vs 多数类基准 42.59%，pooled 不显著；仅 1/21 品种显著。
- 分年度 2022（36.89% vs 34.99%）和 2026（43.52% vs 41.12%）显著，但 2023~2025 均低于基准：
  **方向随年份翻转**，不构成稳定边界。
- 净夏普 pooled −0.149，中位数 −0.149。

### 3.5 L4 横截面相对强弱（rank IC 为主指标）

- 验证段平均 IC **−0.0098**（模型在验证段就没有正向关系，选定 alpha=0.1 仅为流程完整）。
- 测试段：平均 IC **0.0129**，95% CI **[−0.0296, 0.0554]**，t=0.595，p=0.552，
  正 IC 日期占比 49.74%（CI [46.88%, 52.61%]）→ **不显著**。
- IC 衰减（同一分数 vs 未来 1/3/5/10 日收益）：

| horizon | 平均 IC | p 值 | 95% CI |
|---|---:|---:|---|
| 1 日 | 0.0126 | 0.194 | [−0.0064, 0.0317] |
| 3 日 | 0.0085 | 0.608 | [−0.0240, 0.0410] |
| 5 日 | 0.0129 | 0.552 | [−0.0296, 0.0554] |
| 10 日 | 0.0222 | 0.448 | [−0.0352, 0.0796] |

  （t 值按 horizon 重叠做 `n_eff = n/horizon` 保守修正；IC 未随 horizon 单调增长，不是稳定信号。）

- 分板块：黑色 +0.0654（t=1.77，p=0.077）、农产品 −0.0451（t=−1.18）、能源化工 +0.0162（t=0.41）；
  有色/贵金属/金融同日成员 <4 个，无法计算 rank IC。**方向在板块间翻转**。
- 多空组合（每日按得分分三档，多头部/空尾部，等权，按 fwd1 计日收益）：
  毛夏普 +0.042，**扣成本 −0.439**；日均换手 1.02，成本约 3.16 bps/日；最大回撤 −42.76%。
  典型「毛收益接近 0、被成本吃掉」的无效信号。

### 3.6 L5 预测区间覆盖率（80% 名义）

| 年份 | 覆盖率 | 是否显著偏离 80% | 净夏普 |
|---|---:|---|---:|
| 2022 | 81.50% | 是 | −11.02（交易次数极少，不具经济意义） |
| 2023 | 90.57% | 是 | −8.53 |
| 2024 | 88.74% | 是 | −0.668 |
| 2025 | 90.32% | 是 | 0.000 |
| 2026 | 83.13% | 是 | −0.202 |
| 合计 | **87.01%**（CI [86.58%, 87.42%]） | 是 | −0.814 |

- 20/21 品种显著，但方向是**覆盖过度**：验证段（2021）残差分布比测试段更宽，
  导致区间系统性过宽。这属于**区间校准偏差**，不是预测能力。
- 区间交易信号只在「整个 80% 区间都在 0 以上/以下」时开仓，24,442 个样本只产生 26 次换手，
  绝大多数品种不成交；净夏普没有经济意义。

## 4. 结论

1. **可交易边际：没有。** 六个标签的扣成本净夏普全部为负（pooled 口径），逐品种中位数也全部 ≤0。
   毛夏普最高的是 L4（+0.042），扣成本后被换手成本完全吃掉。
2. **统计规律：只有一条。** 未来 5 日波动率状态可预测（51.73% vs 39.25%，
   日期聚类 CI 下界 50.92%，13/21 品种、2023~2026 四个年度显著），
   但它**没有方向内容**，无法转化为多空收益。
3. **L5 的显著性来自校准偏差**：87% 实际覆盖 vs 80% 名义，区间过宽，不是边际。
4. **方向、大波动、三分类、横截面相对强弱**：命中率/IC 与基准无差异，且分年度方向不稳定。
5. 因此如实结论：**现有日线数据与特征集不足以产生可交易边际**。
   继续在同一数据上换模型/调参，预期只会得到更多“统计显著但不可交易”的结果。

## 5. 要达成可交易边际，还缺什么

按优先级排列（每项都给出用途与最小规模）：

| 优先级 | 数据/特征 | 用途 | 最小要求 |
|---|---|---|---|
| P0 | **5/15 分钟日内 bar** | 日内已实现波动、成交量分布、VWAP 偏离、开盘/收盘效应、订单流代理；让波动率标签从“日线近似”变为可交易的风险预测 | 21 品种 × ≥3 年 × 5/15 分钟 |
| P0 | **近月/次近月/主力单合约日线** | 期限结构、基差、月差、展期收益（carry）；这是商品期货最经典的非方向性边际来源 | 每品种 3 个合约 × ≥3 年 |
| P1 | **分席位持仓（前 20 多/空）** | 持仓拥挤度、席位增减仓、产业/投机结构 | 日频 × ≥3 年 |
| P1 | **复权后的连续合约 + 换月日历** | 消除拼接跳空对收益/波动标签的污染；换月成本可精确计入 | 全品种、全历史 |
| P2 | **跨品种同步价差**（rb-hc、i-j、y-p、m-rm 等） | 配对/价差标签与横截面套利；当前只用连续合约排名，无法构造真实价差 | 同一时点、同一合约月份 |
| P2 | **逐笔/盘口或 1 分钟成交明细** | 微观结构特征、真实滑点与冲击成本；当前成本固定 1 tick，偏低/偏高都可能 | ≥1 年 |
| P3 | 交易所结算价、限仓、仓单/库存 | 基本面与交割约束，辅助解释极端行情 | 日频 × ≥3 年 |

**最小可行下一步**（若只能补一项）：先补 **5/15 分钟日内数据 + 近远月单合约**。
前者能让波动率标签变成可交易的风险预测（波动率目标/风险平价），后者能产生
carry/基差类非方向性标签；这两类是当前日线+连续合约数据完全无法覆盖的。
