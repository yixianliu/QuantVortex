# 策略参数调优教程

本框架内置 5 套策略，参数均可在 UI（策略标签页）或代码中实时调整，无需改源码。

## 一、各策略参数速查

| 策略 | 关键参数 | 含义 | 调大效果 |
|------|----------|------|----------|
| 趋势跟踪 | `fast` / `slow` | 快/慢均线周期 | 慢线越大→信号越少、更过滤噪声 |
| 趋势跟踪 | `stop_mult` | ATR 跟踪止损倍数 | 越大→止损越宽、回撤越大但拿得更久 |
| 突破交易 | `period` | 唐奇安通道周期 | 越大→突破更滞后、信号更少 |
| 突破交易 | `stop_mult` | ATR 止损倍数 | 同上 |
| 网格交易 | `grid_step` | 网格间距（价格） | 越大→加仓更稀疏、波动容错更高 |
| 网格交易 | `grid_count` | 最大网格层数 | 越大→最大持仓上限越高（风险↑） |
| 均值回归 | `period` / `num_std` | 布林周期 / 标准差倍数 | `num_std` 越大→触发更少 |
| 马丁策略 | `base_qty` / `multiplier` | 底仓 / 加仓倍数 | `multiplier` 越大→亏损加仓越激进（危险） |
| 马丁策略 | `max_layers` | 加仓层数封顶 | 限制极端行情下的爆仓速度 |
| 马丁策略 | `take_profit` / `stop_loss` | 止盈 / 止损比例 | 影响单笔盈亏与触发频率 |

## 二、调优方法论

1. **先定品种特性**：趋势品种（如部分金属、能化）用趋势/突破；震荡品种（如部分农产品）用网格/均值回归。
2. **用回测定位区间**：修改参数 → `python examples/run_backtest.py` → 看夏普/回撤/胜率。
3. **避免过度拟合**：不要为单一历史区间调出「完美曲线」；用不同 `seed` / 不同年份数据交叉验证。
4. **关注稳健性指标**：高夏普 + 低回撤 + 合理交易次数，优于单纯高收益。
5. **风控先行**：无论策略多好，先确认 `config/settings.json` 的 `risk` 阈值能挡住极端行情。

## 三、常见坑

- **马丁策略**：`multiplier` 与 `max_layers` 决定爆仓速度，实盘务必下调并充分仿真。
- **趋势策略在震荡市**：会出现连续小亏，属正常；靠 `stop_mult` 控制单笔亏损。
- **滑点/手续费**：回测已含滑点与双边手续费，若实盘成本更高，结果会逊于回测。

> 所有回测默认使用**合成行情**（`data/synthetic.py`），仅验证逻辑；
> 实盘参数务必用**真实历史数据**在仿真环境重新校准。
