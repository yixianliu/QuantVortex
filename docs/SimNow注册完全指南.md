# SimNow 注册完全指南（手把手教程）

> 📌 本指南引导您完成 SimNow 仿真账号的注册和查询。全程免费，约需 10-15 分钟。

---

## 第一步：访问 SimNow 官网

1. **打开浏览器**（Chrome/Edge/Firefox 均可）
2. **输入网址**：在地址栏输入 `http://www.simnow.com.cn`
3. **按回车键**访问网站

> 💡 注意：是 `simnow.com.cn`，不是 simnow.cn（少了个 .com）

---

## 第二步：找到注册入口

1. **观察页面顶部**，找到"开户"或"注册"按钮
   - 通常位于页面右上角或导航栏
   - 可能显示为绿色或蓝色的高亮按钮

2. **点击按钮**，会跳转到注册页面

---

## 第三步：填写注册信息

注册表单通常需要填写以下内容：

### 必填项（带 * 号）：

| 字段 | 填写说明 | 示例 |
|------|---------|------|
| **手机号** | 您的真实手机号（需接收短信验证码） | 138****1234 |
| **验证码** | 点击"获取验证码"后收到的6位数字短信 | 123456 |
| **邮箱** | 常用邮箱（用于接收账号信息） | myname@email.com |
| **密码** | 设置登录密码（建议8位以上，含字母+数字） | MyPass123 |
| **确认密码** | 再次输入密码 | MyPass123 |

### 选填项（可跳过）：
- 姓名（仿真交易不需要真实身份验证）
- 身份证号（仿真交易不需要）

---

## 第四步：提交注册

1. **勾选协议**（如果有）：
   - 找到类似"我已阅读并同意《SimNow服务协议》"的复选框
   - 打勾 ✓

2. **点击"提交"或"注册"按钮**

3. **等待结果**：
   - ✅ 成功：显示"注册成功"或跳转到登录页
   - ❌ 失败：检查错误提示（手机号已存在？密码太简单？）

---

## 第五步：登录查询账号信息

注册成功后，按以下步骤查询您的账号：

### 方法 1：通过官网查询

1. **返回 SimNow 首页**：http://www.simnow.com.cn
2. **点击"登录"**
3. **输入刚才设置的密码登录**
4. **登录后**：
   - 找到"我的账号"、"账户信息"或"投资者账号"栏目
   - 记录以下信息：
     - **用户名/资金账号**：通常是 9 位数字（如 `123456789`）
     - **密码**：您刚才设置的密码

### 方法 2：查看注册邮件

如果您注册时填写了邮箱：
1. 打开邮箱（QQ邮箱/163邮箱/企业邮箱等）
2. 搜索关键词："SimNow" 或 "simnow.com.cn"
3. 查找系统自动发送的欢迎邮件
4. 邮件中通常包含您的账号信息

---

## 第六步：测试登录

### 在 SimNow 客户端测试

1. **下载 SimNow 客户端**：
   - 在官网找到"客户端下载"或"交易软件"
   - 下载最新版（通常是"CTP仿真交易系统"）

2. **安装并打开客户端**

3. **配置登录**：
   - 服务器类型选择：**仿真环境** 或 **SimNow**
   - 服务器地址：`180.168.146.187:10211`（行情）+ `10201`（交易）
   - 用户名：您的 SimNow 用户名
   - 密码：您的 SimNow 密码
   - 经纪商代码：`9999`（SimNow 专用）

4. **点击"登录"**

5. **成功标志**：
   - 登录状态显示"已连接"
   - 能看到账户信息界面
   - 可能有持仓或资金余额显示（仿真账户余额通常为虚拟的）

## 常见问题解答

### Q1: 收不到短信验证码？
**A:** 
- 检查手机号是否填写正确
- 确认手机信号正常
- 尝试更换手机号或使用备用手机
- 等待 1-2 分钟后重新获取（短信有频率限制）

### Q2: 提示"手机号已注册"怎么办？
**A:**
- 说明您之前已经注册过
- 使用"忘记密码"功能找回
- 或直接尝试用手机号 + 猜测的密码登录

### Q3: 密码忘了怎么办？
**A:**
- 点击登录页面的"忘记密码"
- 输入注册手机号，通过短信验证码重置
- 或联系 SimNow 客服（官网有联系方式）

### Q4: 登录显示"用户名或密码错误"？
**A:**
- 检查用户名是否输入正确（数字，无空格）
- 确认密码大小写（密码区分大小写）
- 尝试使用"忘记密码"重新设置

### Q5: SimNow 什么时候可以用？
**A:**
- **交易日 8:30-15:00**：正常交易时间
- **交易日 20:30-08:30**：夜间仿真时间
- **非交易日**：部分时段可用（通常上午 8:30 后开放）
- **系统维护**：偶尔会有维护时间，无法登录

## 第八步：回到项目配置

获得 SimNow 账号后，按照以下步骤配置：

1. **打开配置文件**：
   ```
   D:\PythonProject\QuantVortex\config\ctp_settings.json
   ```

2. **修改第 19-20 行**：
   ```json
   "account": {
       "user_id": "您刚注册的SimNow用户名",
       "password": "您的SimNow密码"
   },
   ```

3. **保存文件**（Ctrl + S）

4. **测试连接**：
   ```cmd
   cd D:\PythonProject\QuantVortex
   D:\anaconda3\python.exe -c "from futures_quant.data.ctp_gateway import CTPCredentials, CTPFeed; creds = CTPCredentials.load(); feed = CTPFeed(creds); print('连接:', '✓成功' if feed.connect() else '✗失败')"
   ```
