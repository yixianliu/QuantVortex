## 方向一：新增分析能力

### 具体目标
在现有「分析展示」系统上升级为「可回测 + 可预警 + 预测更强」的闭环，落地三块能力：
1. **策略回测模块**：内嵌可配置回测（均线/突破/网格/事件研究），复用「回测明算」的 pandas 框架，输出 equity/trades/summary + 简易图表。
2. **自选 / 预警增强**：自选品种的价格/技术/资金异动推送 + 阈值预警（本地通知 + 日志）。
3. **KP预测模型调优**：在现有 LSTM 上扩展特征工程（量价/资金/估值因子）+ 多周期集成。

### 预期成果

- 自选列表支持异动预警，运行时在状态栏/日志给出提示。
- 预测模块预测误差较当前基线下降（目标 MAE 改善 10%~15%，以测试集为准）。
