【软件一句话简介】
QuantVortex 是一款面向个人期货交易者的桌面级一体化分析工具。它把
"看盘 → 分析 → 预测 → 回测 → 验证"全流程整合到本地一台 Windows 电脑上，
解压即用、无需安装 Python、断网也能用。软件不替你下单，只把你从繁琐、
易错、耗时的分析劳动中解放出来，让你把精力集中在真正需要判断的地方。


----------------------------------------------------------------
一、您在日常交易中遇到的核心痛点
----------------------------------------------------------------

1. 信息过载，多空难辨
   几十个品种、多个周期同时盯，技术指标、资金流向、新闻、板块联动散落
   各处，顾此失彼，常常错过关键信号。

2. 想法无法验证
   脑子里有个交易思路，却不知道它在历史数据上到底赚不赚钱，只能凭感觉
   硬上。

3. 回测门槛高
   写代码、清洗数据、模拟撮合，对非程序员来说寸步难行，想验证策略却无
   从下手。

4. 预测是"黑箱"
   市面上的预测工具往往只给一个方向，不给置信度、不给历史校准、没有可
   验证依据，你不知道该不该信。

5. 被云服务绑架
   必须联网、必须注册、必须持续付费，断网即瘫痪；更担心自己的持仓和数
   据暴露给第三方平台。

6. 工具链分散
   行情、指标、新闻、回测各在不同平台，数据孤岛严重，来回切换既费时又
   容易出错。


----------------------------------------------------------------
二、本软件为您解决的实际问题
----------------------------------------------------------------

针对上面每一条痛点，QuantVortex 都给出了对应解法：

1. 行情全景一张图
   覆盖 39 个期货品种、6 大板块（黑色 / 有色 / 贵金属 / 能化 / 农产品 /
   金融），市场状态、涨跌分布、资金流向、板块强度一目了然；点击即可跳
   转单品种研判或一键回测，不再来回切换。

2. 有想法先回测，不用猜
   内置 5 种经典策略模板（趋势跟踪 / 突破交易 / 网格交易 / 马丁策略 / 均值
   回归），开箱即用；可视化界面点点选选就能回测，用历史数据验证你的想
   法是否真的有效。

3. 零代码也能做专业回测
   遗传算法自动进化策略参数，不需要你懂编程、不需要手动调参，系统基于
   历史绩效自动迭代寻优。

4. 预测结果可解释、可验证
   KP 趋势预测模型输出带 ±1σ 置信带的曲线，并配套多空力度、压力/支撑
   位、风险度、多空性价比、行情状态，结论看得见、信得过。

5. 本地优先，断网不瘫痪
   绿色便携、解压即用、离线可跑，数据主权完全在你自己手里，不再被云服
   务商绑定。

6. 一个软件内闭环完成全流程
   看盘、分析、预测、回测、验证在一个软件内打通，数据互通，告别数据孤
   岛。

三、本软件带来的独特价值
----------------------------------------------------------------

1. 把"多维研判"压进一个页面
   自动并行计算 20+ 技术指标（MACD / KDJ / RSI / BOLL / DMI / CCI /
   OBV），叠加 KP 趋势预测曲线与 13 个资讯源并发抓取的新闻情绪，一次性
   输出完整的研判结论。

2. 科学闭环：预测 → 回测 → 优化 → 再预测
   盈利策略自动沉淀并反哺预测模型调参方向，让分析能力越用越准；防未来
   函数设计保证回测结果真实可信。

3. AI 研判可选、断网不降级
   可接入云端大模型做自然语言解读；未接入时自动降级为本地规则合成，核
   心分析、预测、回测功能一项不少。

4. 真正的数据主权
   解压即用、离线可跑；SQLite 数据库与用户配置保存在本地 data\ 目录；
   云端密钥仅内存持有、不落盘，公开分发包不含任何上游密钥。

5. 全市场上帝视角
   39 个品种、六大板块、多周期（1 分钟 ~ 周线）切换，综合仪表板实时呈现
   9 项关键 KPI，一键导出全市场快照（ZIP）便于复盘存档。

  能全部可用；兼容 Windows 10（版本 1909+）与 Windows 11。

六、快速上手
----------------------------------------------------------------

绿色便携版（推荐）：
  1. 将 dist\FuturesQuant\ 目录整体复制到硬盘任意位置（建议路径不含中文
     或特殊字符）。
  2. 双击 FuturesQuant.exe 启动；首次运行自动创建 data\ 目录。
  3. 如需接入云端研判，在 PowerShell 中执行：
     [Environment]::SetEnvironmentVariable("QV_AGNES_API_KEY", "sk-xxx", "User")

开发者从源码运行：
  python -m venv venv && venv\Scripts\activate
  pip install -r requirements.txt
  python main.py
