## 二、带来的独特价值（为什么选我们）

1. **把"多维研判"压进一个页面**
   自动并行计算 **20+ 技术指标**（MACD / KDJ / RSI / BOLL / DMI / CCI / OBV），
   叠加 KP 趋势预测曲线、13 个资讯源并发抓取的新闻情绪，一次性输出：
   K 线 + 副图指标 + 预测曲线 + 多空力度 + 压力/支撑 + 风险度 + 多空性价比 + 行情状态。

2. **"有想法先回测，不用猜"的科学闭环**
   内置 5 种策略模板 + **遗传算法（GA）自动进化参数**（变异 / 交叉 / 选择，基于历史绩效迭代寻优），
   **防未来函数设计**（信号在下一根 K 线开盘价撮合），回测结果真实可信；
   盈利策略自动沉淀并反哺预测模型调参，形成「预测 → 回测 → 优化 → 再预测」持续改进闭环。

3. **AI 研判可选、断网不降级**
   可接入云端大模型做自然语言解读；**未接入时自动降级为本地规则合成**，核心分析、预测、回测功能一项不少。

4. **真正的数据主权**
   解压即用、离线可跑、SQLite 与用户配置保存在本地 `data\` 目录；
   云端密钥仅内存持有、不落盘，公开分发包不含任何上游密钥。

5. **全市场上帝视角**
   39 个期货品种、六大板块（黑色 / 有色 / 贵金属 / 能化 / 农产品 / 金融），
   多周期（1 分钟 ~ 周线）切换，综合仪表板实时呈现 9 项关键 KPI，一键导出全市场快照（ZIP）便于复盘存档。

## 三、核心功能模块

### 1. 预测操作 —— 多维研判，一个页面搞定
- 选品种、选周期，自动出 **20+ 技术指标** 与 **带置信带的预测曲线**。
- AI 综合研判可选（云端大模型 / 本地规则降级双模式）。
- 13 个资讯源并发抓取，新闻情绪自动融合进结论。

### 2. 回测中心 —— 有想法先回测，不用猜
- 5 种经典策略模板：趋势跟踪 / 突破交易 / 网格交易 / 马丁策略 / 均值回归。
- 遗传算法自动进化参数，绩效归因自动分解收益来源。
- 防未来函数设计，结果真实可信。

### 3. 行情全景 —— 全市场状态，一张图看清楚
- 39 个品种 / 6 大板块，多周期切换。
- 市场状态、板块强度、涨跌分布、资金净流入/流出实时整合；榜单可点击排序并触发研判或回测。

### 4. 本地优先，绿色便携
- 解压即用：复制 `dist\FuturesQuant\` 目录，双击 `FuturesQuant.exe` 即可，无需安装 Python 或运行库。
- 离线可用：内置合成行情引擎与本地预测模型，断网状态核心功能全部可用。
- 兼容 Windows 10（版本 1909+）与 Windows 11。

## 五、快速开始

**绿色便携版（推荐）**

1. 将 `dist\FuturesQuant\` 目录整体复制到硬盘任意位置（建议路径不含中文或特殊字符）。
2. 双击 `FuturesQuant.exe` 启动；首次运行自动创建 `data\` 目录。
3. 如需接入云端研判，设置环境变量（PowerShell）：

```powershell
[Environment]::SetEnvironmentVariable("QV_AGNES_API_KEY", "sk-xxx", "User")
```

**开发者从源码运行**

```bash
python -m venv venv && venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 六、安全与信任

- **密钥不落盘**：API 密钥仅在内存中持有，不写入任何持久化文件；打包模式强制通过环境变量 `QV_AGNES_API_KEY` 注入。
- **构建三重门禁**：源码扫描 → 产物字节级扫描 → 凭据文件黑名单 + 配置字段核查。
- **产物不含上游密钥**：公开分发的绿色包不包含任何上游 AI 密钥，云端能力由用户自行注入，未注入自动降级本地规则。
