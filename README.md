## 一、软件为用户解决的核心问题

### 1. 信息过载，多空难辨
**用户痛点案例**：交易员同时盯盘螺纹钢、铁矿石、焦炭等黑色系多个品种，配合贵金属、农产品、化工等板块，多周期叠加后指标窗口、资金流、新闻信息分散在不同软件。行情突变时，左侧交易软件K线已涨停，右侧新闻客户端才推送刺激政策，错过入场点；板块联动信号如“原油上涨带动沥青、燃料油”难以快速捕捉，导致多空判断摇摆。

**解决方案**：行情全景页统一呈现39个期货品种、6大板块的全市场速览表，自动计算20+技术指标并叠加KP趋势预测曲线。实时涨跌家数、市场广度、资金净流入、板块强度榜与持仓异动一屏展示，11源财经资讯并发抓取并做情绪研判与置信度加权。用户可一次看到K线+指标+预测+多空力度+风险度的完整图景，关键信号不再遗漏。

### 2. 想法无法用数据验证
**用户痛点案例**：有交易员观察到“螺纹钢夜盘放量突破前高后次日延续”的经验，靠手动翻历史K线验证，一周也查不完。更复杂的“均线多头排列+RSI金叉+持仓量同步放大”组合条件，手工统计误差大，容易出现幸存者偏差，盲目跟单导致亏损。

**解决方案**：内置5种策略模板与自动进化引擎，支持参数遗传算法优化。用户用图形化界面描述“突破+量价配合+持仓确认”逻辑，一键运行事件驱动回测。回测引擎防未来函数，严格模拟开平今/平昨差异化手续费、动态保证金、涨跌停扩板、移仓换月成本，结果真实可信。让“先想后测”成为交易习惯。

### 3. 回测门槛过高
**用户痛点案例**：非程序员想验证“开盘前5分钟突破昨日高点”的日内策略，需要写代码清洗数据、处理夜盘断层、模拟滑点与涨停限制。普通用户在Python环境配置、数据对齐、撮合逻辑上耗费数周，最后因未来函数导致回测曲线虚高，实盘即崩。

**解决方案**：零代码图形化回测中心，数据导入自动对齐主力连续合约与三重复权，撮合引擎内置固定/比例/波动率自适应滑点、涨跌停扩板、逐日盯市。用户仅需拖拽参数、选择周期，点击运行即可获得收益、风险、交易、资金四维绩效报告，输出资金曲线、回撤曲线、月度收益热力图，门槛降至点击级别。

### 4. 预测结果不可信
**用户痛点案例**：市面上AI预测工具常给出“明天大涨90%概率”，实盘却连错。原因在于模型用全量数据归一化、随机切分训练集，产生未来泄漏；无样本外校准，随机游走也能输出高置信度。用户无法判断预测的可信度，只能被动接受。

**解决方案**：AI预测模块采用滚动窗口z-score归一化、时序切分+embargo隔离带、Walk-Forward滚动验证，并以Mincer-Zarnowitz回归做样本外校准，通过t统计量显著性收缩beta。每条预测均附点预测、95%置信区间、涨跌概率、预期收益、特征贡献度与历史准确率。预测可解释、可回溯，不虚报信心。

### 5. 云服务绑定
**用户痛点案例**：某量化软件要求注册账号、每月付费，断网后无法使用。交易数据上传云端，历史行情与策略参数外泄风险高。外出或网络不稳定时无法看盘，回测需等待云端排队，效率低下。

**解决方案**：绿色便携解压即用，SQLite本地存储，核心密钥仅内存持有。所有核心功能——指标计算、AI预测、回测、风控——均离线可用。无需注册、无强制联网，数据主权完全掌握在用户手中，断网也能完整运行。

### 6. 工具链割裂
**用户痛点案例**：行情用Wind，指标用TradingView，新闻用财联社，回测用自研Python脚本，数据需反复导出导入。不同工具时间戳不一致，持仓与资金流口径不统一，导致分析结论自相矛盾。

**解决方案**：全流程闭环看盘→分析→预测→回测→验证，一站式完成。数据层、计算核心、回测、AI、UI五层解耦却数据互通，无需导出导入。同一品种的K线、指标、预测、回测结果口径一致，避免数据孤岛。

### 3. AI 解读可选，本地核心不丢
**独特描述**：AI 预测与自然语言解读为增值选项，非核心依赖。模型采用 Walk-Forward 滚动验证 + Mincer-Zarnowitz 样本外校准，输出点预测 + 95%置信区间 + 涨跌概率 + 特征贡献度。离线时自动降级为本地规则引擎，指标计算、预测、回测、风控全离线可用，核心功能永不丢失。

**独特描述**：绿色便携 exe，解压即用，SQLite 本地存储，核心密钥仅内存持有。无需注册、无强制联网、无订阅费，个人交易数据与策略参数永不外泄。断网、旅途中也能完整使用，数据主权完全归属用户。

### 5. 全流程闭环
**独特描述**：看盘 → 分析 → 预测 → 回测 → 验证，形成闭环工作流。同一套数据在行情全景、预测操作、回测中心中口径一致，无需重复导入导出。策略优化结果可直接反馈到预测模型特征工程，形成“预测-验证-迭代”的持续改进闭环。

## 三、系统逻辑架构

采用五层解耦架构，杜绝层间数据泄漏：

**数据层** `futures_quant/data`
多数据源接入AKShare/TqSdk、合约管理、主力连续拼接、三重复权、夜盘时段对齐、本地Parquet/SQLite缓存。

**计算核心层** `futures_quant/core`, `futures_quant/indicators`
纯函数化指标计算与策略信号生成，无状态设计，支持单元测试。事件驱动引擎逐K线更新。

**回测层** `futures_quant/backtest`, `futures_quant/broker`, `futures_quant/risk`
事件驱动精准撮合，差异化手续费/保证金/滑点模拟，移仓换月自动处理。风控覆盖单笔止损、总回撤止损、单日最大亏损、保证金风险度预警、单品种仓位上限、涨跌停熔断。

**AI模型层** `futures_quant/ai`
特征工程滚动z-score归一化，抗未来数据泄漏。模型矩阵：XGBoost/LightGBM、LSTM/TCN/Time-Series Transformer、GARCH波动率、PPO强化学习。训练使用Walk-Forward滚动交叉验证，早停/Dropout/L2防过拟合。输出点预测+95%置信区间+特征贡献度。

**界面表现层** `futures_quant/ui`
专业金融深色主题，主背景#1e1e2e，文本#dcdcdc，上涨#ff4757，下跌#2ed573。高信息密度模块化布局：顶部品种/周期配置，左侧导航，中央K线+多副图，右侧AI预测/信号/持仓/风险度，底部绩效报告。

## 四、核心算法原理

**防未来函数设计**  
所有计算严格基于历史时点数据，特征归一化采用滚动窗口，模型训练标签为未来N根K线涨跌方向/涨跌幅，训练验证采用时序切分+embargo隔离带。

**Mincer-Zarnowitz校准**  
样本外校准回归 `actual = a + b * pred`，通过t统计量显著性收缩beta，避免纯噪声模型产生虚高置信度，完美治理随机游走上给出极端概率的问题。

**多步递归外推**  
以最近窗口递归外推，收益特征先映射回z空间再写入，波动槽在原始空间EMA更新后再归一化，防止特征量级错配导致预测发散。

**风险度量化**  
综合ATR占比、近期最大回撤、ADX趋势强度、关键价位距离四维度加权，输出0-100风险分与低/中/高风险标签。

## 五、功能模块实现

**行情全景页**  
全市场速览表、涨跌家数、市场广度、资金净流入、板块强度榜、持仓异动、供需信号、财经资讯智能解读，11源并发抓取+情绪研判+置信度加权。

**预测操作页**  
品种选择、周期/日期范围、AI模型选择、多空方向切换，交互式K线+多副图指标，十字光标读数，AI预测曲线叠加买卖信号标注。

**回测中心**  
策略参数可视化调整、遗传算法优化、回测绩效全维度报告、资金曲线与回撤曲线、交易明细导出PDF/Excel。

**策略体系**  
CTA：双均线交叉、唐奇安通道突破、Dual Thrust、Ichimoku、Keltner、Trailling ATR、Vortex  
统计套利：跨期/跨品种/期现套利、协整检验、无套利区间  
日内短线：开盘突破、成交量异动、改良网格  
波动率：Bollinger、GARCH Timing、HV Percentile

**仓位与资金管理**  
ATR自适应仓位控制单笔风险1%-3%、凯利公式计算、金字塔加减仓、保证金占用率实时监控与风险度预警。
