# FuturesQuant 分发与安装说明

本说明面向**打包 / 分发负责人**，描述如何把期货智能分析预测系统交付给最终用户。

---

## 一、交付物两种形态

| 形态 | 适用场景 | 产物 |
|------|----------|------|
| **绿色目录**（推荐快速分发） | 内网 / 信任环境，直接拷目录 | `dist/FuturesQuant/`（整个文件夹） |
| **安装包**（推荐对外分发） | 需要桌面快捷方式 / 程序组 / 卸载 | `installer_out/FuturesQuant_Setup_*.exe` |

---

## 二、构建 EXE（绿色目录）

前置：本机已装 `pyinstaller`，且运行环境含 `PyQt6 + numpy + pandas`。

```bash
# 在项目根目录
python build_exe.py
```

- 输出：`dist/FuturesQuant/`（含 `FuturesQuant.exe` + 依赖 + `config/`）。
- 主题：深色为主；如需浅色，运行 `FuturesQuant.exe` 后无参默认深色，
  或改 `config/settings.json` 的 `ui.theme`。
- **首次运行**会自动在 exe 同级创建 `data/`（数据库 `quant_analysis.db`、
  用户配置、会话、sina 缓存）；若装在 `Program Files` 等只读目录，自动回退到
  `%APPDATA%/FuturesQuant/data`，功能不受影响。

> 验证：`python main.py --test` 可做核心模块导入冒烟（无 UI）。

## 三、构建安装包（InnoSetup）

1. 先完成「二」得到 `dist/FuturesQuant/`；
2. 本机安装 [InnoSetup](https://jrsoftware.org/isinfo.php)，确保 `iscc` 在 PATH；
3. 编译：
   ```bash
   iscc packaging\installer.iss
   # 或双击 packaging\build_installer.bat
   ```
4. 产物：`installer_out/FuturesQuant_Setup_<版本>.exe`。

安装包行为：
- 安装到 `Program Files\FuturesQuant ...`（非管理员也可装到用户目录）；
- 创建桌面快捷方式（可选）与程序组；
- 首次运行由程序自动初始化数据目录（见上）；
- 卸载保留用户 `data/`（可在 `installer.iss` 取消 `UninstallDelete` 注释改为清空）。

## 四、代码签名（消除 SmartScreen / 未知发布者）

未签名 exe 在 Windows 上会被 SmartScreen 拦截为「未知发布者」。可选签名步骤：

1. 获取代码签名证书（二选一）：
   - **普通代码签名证书**（OV）：便宜、签发快，但新证书 SmartScreen 信誉需累积；
   - **EV 代码签名证书**：贵、需硬件令牌，自带 SmartScreen 即时信誉（推荐对外分发）。
2. 安装 Windows SDK（含 `signtool.exe`）并将其加入 PATH；
3. 设置环境变量后重新构建，自动签名：
   ```bash
   set QV_SIGN=1
   set QV_SIGN_THUMBPRINT=<你的证书 SHA1 指纹>
   :: 或用主题名：set QV_SIGN_SUBJECT=<证书主题名>
   set QV_TIMESTAMP_URL=http://timestamp.digicert.com
   python build_exe.py
   ```
   - 脚本会对主 exe 及所有捆绑的 `.dll/.pyd` 签名并带时间戳；
   - 若 `signtool` 或证书缺失，自动跳过并提示，**不阻断构建**。

## 五、CTP / 实盘行情（可选）

默认数据源为**新浪公开日线（真实、免密钥）**。若要接入期货公司 / SimNow 实时行情：

1. 复制模板并填入凭据（**绝不入库**）：
   ```bash
   cp config/ctp_settings.example.json config/ctp_settings.json
   ```
2. 本机安装 `vnpy_ctp` 或 `ctpbee` + 对应期货公司 CTP 动态库；
3. 在 `config/settings.json` 把 `data.source` 设为 `"ctp"`，或在程序「实盘监控」页点「连接柜台」；
4. 详见 `docs/ctp_wiring.md`。**交易侧默认不启用**（系统定位为分析预测，不做自动交易）。
